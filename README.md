# 🚀 Jornada C: Rumo à Certificação CLA & Código Limpo

Bem-vindo ao meu repositório de estudos focado na linguagem **C**! Este espaço foi criado para consolidar meu aprendizado diário, organizar meus códigos e acompanhar meu progresso rumo à certificação **CLA (C Certified Associate Programmer)**.

---

## 🎯 Objetivos do Repositório

* **Prática Diária:** Resolução de algoritmos, estruturas de dados e desafios lógicos em C.
* **Preparação CLA:** Exercícios baseados nos tópicos do exame (ponteiros, gerenciamento de memória, diretivas de compilação, etc.).
* **Evolução com Clean Code:** Aplicação gradual das boas práticas do livro *Código Limpo*, melhorando a legibilidade e a estrutura do código a cada capítulo lido.

---

## 🛠️ Conteúdo do Repositório

Como os arquivos estão organizados:
* `/fundamentos` — Tipos de dados, operadores e estruturas de controle.
* `/funcoes_e_ponteiros` — Modularização, escopo e manipulação de memória (foco CLA).
* `/desafios` — Problemas complexos e simulados de lógica.
* `/clean_code_refactor` — Códigos antigos que foram reescritos aplicando conceitos de Clean Code.

---

## 🧠 Filosofia de Desenvolvimento

> "Qualquer tolo pode escrever código que um computador entenda. Bons programadores escrevem código que humanos podem entender." – Martin Fowler

Estou no início da leitura de *Código Limpo*, portanto, muitos códigos iniciais podem parecer "crus". O objetivo principal deste repositório é documentar a **evolução**, mostrando o "antes e depois" da aplicação das técnicas de refatoração por capítulo.

---

## ⚙️ Como Executar os Projetos

Para compilar e rodar qualquer arquivo deste repositório, você precisará de um compilador GCC instalado.

```bash
# Clonar o repositório
git clone https://github.com

# Entrar na pasta do exercício
cd jornada-c-cla

# Compilar o arquivo
gcc nome_do_arquivo.c -o programa

# Executar
./programa
```
